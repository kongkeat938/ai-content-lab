น้อยกว่าเพื่อไปถึง 1,000 subs เท่ากัน.

**UNKNOWN:** ตัวเลข 489 / 0.41% มาจากตัวอย่างเล็ก (11 คลิป) — ยังไม่ยืนยันว่าเสถียร.
งานใน 30 วันแรกคือ **ทดสอบว่าเสถียรหรือไม่** ก่อนเทคอนเทนต์ทั้งหมดลงช่องเดียว.

## 2. การเปลี่ยน FORMAT ที่คุ้มที่สุด — 1 อย่างต่อช่อง (falsifiable)

### ch2 — เปลี่ยนแกนจาก "ธรรมะ 10–12 นาที" เป็น **compilation ช่วยนอน 90–180 นาที**
- **หลักฐาน:** long-form 10–12 นาทีของช่องเอง เฉลี่ย **2 วิว** (ตาย) แต่คู่แข่งไทยที่
  ชนะใน niche เดียวกัน (พลังแสงแห่งธรรม 130k, Dhamma Buddh 130k) ชนะด้วย
  **compilation 82–240 นาที** → ปัญหาไม่ใช่ "คลิปยาว" แต่คือ "คลิปยาวแบบ talk".
  compilation = คลิปยาวแบบ **หลับคาไว้** (ภาพนิ่ง + เสียงต่อเนื่อง) = เครื่องปั่นชั่วโมงดู.
- **Falsifiable:** ภายใน 30 วัน ปล่อย 4 compilation (90/120/150/180 นาที). ผ่านเกณฑ์
  เมื่อ (a) compilation ≥ 100 วิว ใน 7 วัน และ (b) ≥ 1 compilation ติด **top-3 ของช่อง**
  ตามวิว. ถ้าไม่ผ่าน = สมมติฐาน compilation ตก.
- **UNKNOWN:** ชั่วโมงดู (watch-hours) วัดจาก API ไม่ได้ — YouTube Analytics API
  ถูกปิดบน GCP project → ต้องวัดด้วย public view count แทน.

### ch4 — เปลี่ยนจาก parable เดี่ยว เป็น **ดราม่าครอบครัวแบบซีรี่ส์มีเลขตอน**
- **หลักฐาน:** Shorts ธีมดราม่าครอบครัว 1,079/460 วิว vs ธีมคำเปรียบธรรมชาติ ~100 วิว
  (ต่างกัน ~10 เท่า). angle ของช่องเองก็คือ "ซีรี่ส์ที่ติดตามตอนต่อตอน".
- **Falsifiable:** ทำซีรี่ส์ 5 ตอน (มี "ตอนที่ N" ในชื่อและบนจอ). ผ่านเกณฑ์เมื่อ
  ตอนที่ 2–5 **แต่ละตอนได้ ≥ 50% ของวิวตอนที่ 1** ภายใน 7 วันหลังโพสต์.
  ถ้าตอนท้ายร่วง = สมมติฐาน serialization ตก.

### ch1 — เปลี่ยนจาก talk 11 นาที เป็น **"ความคิดเดียว" 23–30 นาที + ชื่อเป็นประโยคความรู้สึก**
- **หลักฐาน:** long-form 11 นาทีของช่อง เฉลี่ย **6 วิว**; ช่องไทยเล็ก ข้อคิดชีวิต
  (5,320 subs) ทำ **23–30 นาที "one quotable idea" + ชื่อประโยคความรู้สึก** ได้ 30k+ วิว.
  ต่างกันที่ความยาวและ**ชื่อเรื่อง** ไม่ใช่แค่เนื้อหา.
- **Falsifiable:** ภายใน 30 วัน ปล่อย 3 คลิปความยาว 23–30 นาที ชื่อเป็นประโยคความรู้สึก.
  ผ่านเกณฑ์เมื่อ **≥ 1 คลิปได้ ≥ 30 วิว** (5 เท่าของ median 6 วิว) และติด top-5 ของช่อง.
- **หมายเหตุ:** การตั้งชื่อเป็น *กลไก* ไม่ใช่ *format* — จึงยกชื่อมาไว้ในข้อ 3 ด้วย.

## 3. ระบบ Shorts

### ความยาว
- ch2, ch4: **45–70 วินาที**. ch1: **30–50 วินาที**. **เพดานแข็ง 89 วินาที.**
- เหตุผล: long-form ของทุกช่องแย่กว่า Shorts แบบขาด (ch1 6 vs 307, ch2 2 vs 489,
  ch4 2–4 vs ~1,000) → **Shorts เท่านั้นคือเครื่องยนต์**. ไม่มีข้อมูลแยก retention
  ระหว่าง 45s กับ 89s → ช่วงนี้เป็น convention ไม่ใช่ค่าที่วัดได้.

### Hook (1.5 วินาทีแรก)
- **ห้าม** โลโก้, การ์ดชื่อช่อง, "สวัสดีครับ", ดนตรีขึ้นก่อนเสียง.
- เปิดกลางประโยค/กลางเหตุการณ์, **3 คำไทยแรกต้องบอกประธานหรือเดิมพัน** ของเรื่อง.
- **UNKNOWN:** retention วินาทีต่อวินาทีวัดไม่ได้ (Analytics API ปิด) → เป็น convention.
  เช็คได้เท่านั้นว่าไฟล์ไม่มี intro: เฟรมแรก = เนื้อหา.

### Caption
- **เบิร์นซับไทย** ทุกคลิป, **ไม่เกิน 2 บรรทัด**, ตัดตามพิกเซลในกล่อง **900 px**
  (`ops/short_maker.py::_wrap_caption`). ห้ามพึ่งชื่อเรื่องอย่างเดียว เพราะ Shorts
  เล่นแบบปิดเสียง.
- ตรวจ: `ops/test_caption_wrap.py` ต้องผ่าน; ไม่มีบรรทัดล้น 900 px.

### CTA
- **1 ครั้งเท่านั้น**, วางหลังผ่าน **50%** ของความยาว, พูด **และ** ขึ้นบนจอ, ผูกกับ
  คุณค่า ("กดติดตามไว้ ฟังตอนต่อไปคืนนี้") — ห้าม CTA ก่อนครึ่งคลิป (ฆ่า retention).
- **UNKNOWN:** ขนาดผลของ CTA ไม่ได้ A/B วัด → เป็น convention.

### เวลาโพสต์ (ผู้ชมไทย)
- ch2, ch4: **20:00–21:00 ICT** (= 13:00–14:00 UTC) — primetime + ก่อนนอน.
- ch1: **19:00–20:00 ICT** (= 12:00–13:00 UTC).
- **UNKNOWN:** ชั่วโมงที่แม่นที่สุด — ไม่มีข้อมูล per-hour (Analytics API ปิด).

### Cadence ต่อช่อง
- เพดานรวม **≤ 5 คลิป/วัน** (API: `videos.insert` = 1600 units, project 10,000/วัน
  → เพดาน ~6/วัน; และบัญชี Google มีเพดาน ~19 uploads/วันแบบ rolling — ดู Sources).
- จัดสรรตาม leverage: **ch2 = 2/วัน, ch4 = 2/วัน, ch1 = 1/วัน.**

## 4. กลไกแปลง "วิว" เป็น "sub" — เรียงตามผลที่คาด

> **หมายเหตุความซื่อสัตย์:** ไม่มีตัวเลข A/B วัดบน 3 ช่องนี้ (Analytics API ปิด).
> ลำดับนี้เรียงจาก (ก) พฤติกรรมคู่แข่งที่เห็น และ (ข) ตัวเลขที่โปรเจกต์วัดเอง.
> ทุกข้อมี "ทดสอบ falsifiable" กำกับ.

1. **คำสัญญาว่า "มีตอนต่อไป" (serialization)** — แรงสุด. คนกดสมัครเพราะกลัวพลาดตอนหน้า
   ไม่ใช่เพราะชอบคลิปเดียว. *ทดสอบ:* ซีรี่ส์ 5 ตอน ch4; ตอน 2–5 ≥ 50% ของตอน 1.
2. **CTA เดียว ผูกคุณค่า วางท้ายคลิป** — บอกให้ทำตอนที่คนยังดูอยู่. *ทดสอบ:* ใส่ vs
   ไม่ใส่ สลับกัน 10 คลิป; เทียบ subs/วิว. (ยังไม่ทำ → UNKNOWN.)
3. **ลายเซ็นช่องที่จำได้ (เสียง/ภาพ/จังหวะเดียวกัน)** — เมื่อคนหลงมาจาก 1 Short แล้วกด
   เข้าหน้าช่อง ต้องเห็น "ของเดิมอีกเยอะ". *ทดสอบ:* 3 Shorts ปักหมุดแรกหน้าตาเดียวกัน.
4. **คอมเมนต์ปักหมุด + playlist "รวมตอน"** — พาไปตอนอื่นในคลิกเดียว (เพิ่ม session →
   เพิ่มโอกาสกดสมัคร). *ทดสอบ:* คลิปที่มี pinned comment vs ไม่มี.
5. **โพสต์เวลาเดิมทุกวัน** — สร้างนิสัย "กลับมาทุกคืน" โดยเฉพาะ ch2 (ธรรมะก่อนนอน).
   *ทดสอบ:* คงเวลา 20:00 ICT 14 วัน แล้วดูวิวต่อคลิป.
6. **cross-promo ไปช่องพี่น้องใน description** (ฟรี, ทำอยู่แล้ว) — ช่วยแต่เล็ก.

**ข้อควรระวัง:** วิว ≠ sub. ch1 มีวิวมากสุดแต่ subs/วิว ต่ำสุด → **ไล่ปริมาณวิวอย่างเดียว
ไม่พอ**; ต้องได้วิวจาก *คนที่ตรง niche*.

## 6. สิ่งที่ไม่ควรทำ — พร้อมเหตุผลที่วัดได้

| ห้าม | เหตุผลที่วัดได้ |
|---|---|
| ห้ามโพสต์ long-form talk 10–12 นาที บน ch2 | เฉลี่ย **2 วิว** (vs Shorts 489) |
| ห้ามโพสต์ long-form 11 นาที บน ch1 | เฉลี่ย **6 วิว** |
| ห้ามโพสต์ long-form บน ch4 | **2–4 วิว** |
| ห้ามทำ Shorts ธีมคำเปรียบธรรมชาติ บน ch4 | **~100 วิว** vs ดราม่าครอบครัว 1,079 (~10 เท่า) |
| อย่าหลง "วิวสูง" เก่าของ ch1 (`#1minute english` 1,404 วิว) | อายุ **524 วัน = 2.7 วิว/วัน** — ของเก่า ไม่ใช่สัญญาณ |
| ห้ามซื้อ/ปั่นวิวหรือ sub | YPP นับเฉพาะ **engaged/qualified** views; วิวจากบอต/ไม่ใช่ต้นฉบับ = **ineligible** และผิด policy (ดู Sources) |
| ห้ามรัน uploader สองตัวพร้อมกันบนบัญชีเดียว | เพดาน **~19 uploads/วัน/บัญชี** เป็น rolling window → ตัวที่สองได้ `uploadLimitExceeded` |
| ห้ามใช้ GitHub cron หวัง 24/7 | วัดแล้ว: `total_count=1` scheduled run ทั้งที่ควรได้ ~20 → **cron อ่อน** ต้อง dispatch เองหรือ `workflow_run` |
| ห้ามให้ดนตรีกลบเสียงในจังหวะเงียบ | **AUDIO FIRST** (K): retention คือเสียง, เบดต้องไม่ชนะแม้ใน pause |
| ห้ามดัดแปลงเรื่องต่างชาติ | ep01 (Gift of the Magi) ล้มเหลวเพราะเงิน 1.87 ดอลลาร์คนไทยไม่รู้สึก |

| ห้าม commit token | token อยู่ใน `~/.config/content-lab/` mode 600, gitignored |
| อย่าคาดหวังข้อมูล retention จาก API | YouTube Analytics API **ปิด** บน GCP project → วัดได้แค่ public view count |
