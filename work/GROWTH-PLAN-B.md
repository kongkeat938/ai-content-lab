## 2. THUMBNAIL / COVER RULES (still-image poster, ไม่มี face cam)

กติกาที่ทำให้ CTR ขึ้นจริงบนช่องภาพนิ่ง (อิงสูตรโปสเตอร์ที่วัดไว้: brightness 37–132,
saturation 0.29–0.60, contrast สูง) — ตัวเลข CTR เอง `UNKNOWN` เพราะยังไม่มี Analytics.

1. **อ่านออกที่ 120 px.** ย่อปกเหลือ 120 px แล้วยังอ่านคำหลักได้ ถ้าไม่ได้ = ต้องใหญ่ขึ้น.
   คำหลัก (hook) สูงอย่างน้อย **1/3 ของความสูงเฟรม**.
2. **ไม่เกิน 5–7 คำไทย, ไม่เกิน 2 บรรทัด.** Thai ไม่มีเว้นวรรค → ตัดบรรทัดเองตามความหมาย
   (ห้ามให้ browser/editor ตัดเอง). ใช้ `_wrap_caption` แนวคิดเดียวกับ Shorts.
3. **1 ภาพ = 1 อารมณ์ = 1 ประธาน.** ถ้ามีคน ให้ใช้ใบหน้า/สีหน้าแสดงอารมณ์ (ภาพ public-domain
   หรือ AI ที่ licence อนุญาต + บันทึกใน `assets/images/credits.json`). ถ้าไม่มีคน ใช้ของที่มี
   ความหมายกับอารมณ์ (กล่องจดหมาย, จานข้าว, รองเท้าเก่า) ไม่ใช่ทิวทัศน์สวยเฉย ๆ.
4. **คอนทราสต์สูง: ตัวอักษรขาว/ทอง บนพื้นเข้ม.** พื้นสว่าง + ตัวอักษรเทา = หายไปในฟีด.
5. **ทึบ/มืดที่ขอบ (vignette) + จัดกลาง.** ตาไปที่คำหลักก่อน แล้วจึงเห็นภาพ.
6. **เว้นมุมล่างขวา.** YouTube วางป้ายความยาวคลิปทับมุมล่างขวา — ห้ามมีตัวอักษรสำคัญตรงนั้น
   (กฎเดียวกับ definition-of-done: "no text under the duration badge").
7. **แถบสีแบรนด์ + เลขตอนมุมเดิมทุกคลิป.** ch1 สีหนึ่ง, ch2 สีหนึ่ง, ch4 สีหนึ่ง — คนดูจำช่องได้
   จากสี. ความสม่ำเสมอทำให้รู้ว่า "คลิปนี้ช่องเดิม".
8. **โชว์ตัวเลข/เวลาเมื่อมี.** `3 ชม.`, `12 นาที`, `ตอนที่ 7` บนปกเพิ่มความชัดว่าคลิปยาวแค่ไหน.
9. **3 ช่อง ห้ามปกหน้าตาเหมือนกัน.** ใช้คนละโทนสี + คนละ layout หลัก เพื่อไม่ให้อัลกอริทึม/คนดู
   สับสนว่าเป็นคลิปซ้ำ.
10. **A/B test ปก**: YouTube "Test & compare" — **`UNKNOWN`** ว่าช่องระดับนี้ใช้ได้หรือยัง
    (ต้องเช็คใน Studio). ถ้าใช้ไม่ได้ ให้ทดสอบเองแบบ manual: เปลี่ยนปกคลิปที่ views ต่ำ แล้ววัด
    หลัง 7 วัน.

## 4. THE LONG-FORM COMPILATION PLAY — ch2 (90–180 นาที)

**ทำไมชนะ 12 นาที (เลขล้วน ไม่เดา):**
YPP ต้อง **4,000 ชม./12 เดือน**. คลิป 12 นาทีดูจบ = 0.20 ชม./วิว → ต้อง **20,000 วิว**.
คลิป 150 นาทีดู 30% = 0.75 ชม./วิว → **5,333 วิว**; ดู 50% = 1.25 ชม./วิว → **3,200 วิว**.
คือ **3.75–6.25 เท่าของ watch-hours ต่อวิว**. คนฟังธรรมะก่อนนอนมักเปิดทิ้งไว้ทั้งคืน (ปิดจอ)
→ completion สูงกว่าปกติ. และคลิป >8 นาทีใส่ **mid-roll ad** ได้ (รายได้ทางอ้อม).
หลักฐานคู่แข่ง: พลังแสงแห่งธรรม 130k / Dhamma Buddh 130k ชนะด้วยคลิป **82–240 นาที**.

**ข้อควรระวัง (ซื่อสัตย์):** long-form ch2 ปัจจุบันเฉลี่ย **2 วิว** → compilation **ไม่ใช่กลไก
discovery**. มันคือกลไก **สะสม watch-hours**. discovery ต้องมาจาก Shorts + playlist (§5).

### Recipe — ทำ compilation หนึ่งชิ้นจากของเดิม

1. **เลือก 8–12 ตอน** ธรรมะก่อนนอนที่มีอยู่ (ตอนละ 10–12 นาที) → 100–140 นาที.
   ต้องการ 180 นาที ใช้ ~15 ตอน. (ปัจจุบันมี 11 คลิป → พอทำ ~2 ชม. ได้ 1 ชิ้น.)
2. **ตัดหัว–ตัดท้ายของแต่ละตอน** (สวัสดีครับ/ฝากกดติดตาม) ออก เหลือแต่เนื้อ — ไม่งั้นเสียง
   ทักทายซ้ำทุก 12 นาที ทำให้คนรู้ตัวว่าตื่น.
3. **ต่อเสียงด้วย crossfade 2–3 วินาที** ระหว่างตอน. ระดับเสียงทุกตอนต้องเท่ากันก่อนต่อ
   (แต่ละตอน normalize มา -14 LUFS แล้ว).
4. **ใส่ ambient bed ต่อเนื่องระดับต่ำมาก** — ไม่ให้ดนตรีชนะเสียงพูด **แม้ในจังหวะเงียบ**
   (กฎ K: AUDIO FIRST). ระดับอ้างอิง: bed ต่ำกว่าเสียงพูด ~20 dB (`UNKNOWN` ค่าที่แน่นอน
   จนกว่าจะวัด — ให้วัดด้วย `ffmpeg` ก่อน publish).
5. **ห้ามมี stinger/เพลงเปลี่ยนกระทันหัน.** พลวัตต้องแบนราบ — คนอาจหลับอยู่.
6. **Master ทั้งไฟล์ two-pass `loudnorm` → -14 LUFS, true peak ≤ -3 dBFS.**
   ระวัง AAC overshoot ~0.7 dB → ตั้ง `tp=-2.5` ตอน master.
7. **วิดีโอ:** ปกนิ่งเดียว 1920x1080, `yuv420p`, `color_range=tv` (+ `bt709`).
   encode เป็นคลิปยาวเต็มความยาวตรง ๆ — **ห้ามใช้ `-f concat` กับภาพนิ่ง** (บั๊กตัด 14 วิทิ้ง
   ที่เจอใน ep02).
8. **ใส่ chapters ทุก ~12 นาที** (ชื่อตอน + เวลา) ให้แถบ seek แสดงเป็นช่วง.
9. **Upload + description:** ไล่ชื่อตอนพร้อม timestamp + ที่มา/attribution ครบ.
10. **ปล่อยพร้อม Shorts 2–3 ตัว** ที่ตัดจากคลิปนี้ (ดู §5).

### Cover art (compilation)

- 1280x720, พื้น **กรมท่า/ม่วงเข้มยามค่ำ**, พระจันทร์เสี้ยวหรือเงาเจดีย์/วัด.
- ตัวอักษรใหญ่ขาว/ทอง: **"หลับให้สบาย"** (hook) + บรรทัดรอง **"ฟังก่อนนอน 3 ชั่วโมง"**.
- ป้ายมุม **"3 ชม."** — เวลาคือจุดขาย.
- ≤ 6 คำ, 2 บรรทัด, คำหลัก ≥ 1/3 เฟรม, เว้นมุมล่างขวา.

### Title (compilation)

`ธรรมะก่อนนอน 3 ชั่วโมง | หลับสบายทั้งคืน (รวม <N> ตอน)`

- มีตัวเลข (3 ชั่วโมง, N ตอน) + มี `|` + ประโยคความรู้สึก — ตรงกับ pattern ที่วัดว่าชนะ.
- ทางเลือก: `ฟังแล้วหลับ 3 ชั่วโมง | ธรรมะก่อนนอนรวม <N> ตอน`.

### หลัง publish — วัดอะไร

วัดได้เฉพาะ **views + watch time รวม (จาก Data API)**. **Average view duration / retention /
CTR = `UNKNOWN`** จนกว่า K จะเปิด Analytics API. เปรียบเทียบ watch-hours ต่อวิว กับค่า 12 นาที
เพื่อพิสูจน์สมมติฐาน — ถ้าไม่ดีขึ้น ให้กลับไปทำ 12 นาทีและโฟกัส Shorts.

## 5. CROSS-PROMOTION + SHORTS → LONG FUNNEL

**หลัก:** Shorts = เครื่องยนต์ discovery; long-form = สินค้า; playlist = ทางเชื่อม.

**กลไก Shorts → long (ทำทุกคลิป):**
1. ตัด Short จาก**กลาง**คลิปยาว โดย**จบที่จังหวะค้าง** (ไม่เฉลย) — ให้คนอยากดูต่อ.
2. Shorts **ไม่มีลิงก์ในคำอธิบายที่กดได้** → ใช้ **pinned comment** วางลิงก์คลิปเต็ม
   ("ดูฉบับเต็ม: <URL>") + ใส่ชื่อคลิปเต็มในคำอธิบาย.
3. **ใส่ Short ทุกตัวลง playlist เดียวกับคลิปเต็ม** — YouTube จะเสนอ related ต่อให้เอง.
4. ตั้งค่า Short ให้ "related video" ชี้ไปคลิปเต็ม (ถ้า Studio ให้ตั้ง — `UNKNOWN` ว่าทุกช่อง
   ตั้งได้; ถ้าไม่ได้ ให้พึ่ง pinned comment + playlist).

**End screen (วินาทีสุดท้ายของทุก long-form, 20 วิ):**
- 1 subscribe element + 1 video + 1 playlist.

**Playlists (สร้างเลย สัปดาห์นี้):**
- ch1: `ปรัชญาชีวิต (รวมทุกตอน)`
- ch2: `ธรรมะก่อนนอน (รวมทุกตอน)` + `ธรรมะก่อนนอน 3 ชั่วโมง`
- ch4: `เรื่องเล่าการ์ตูน (ซีรีส์)` เรียงตามเลขตอน.

**Watermark (branding image 150x150, มุมขวาล่าง):** ทำให้ทุกคลิปมีปุ่ม subscribe ลอย —
มีผลกับทั้ง Shorts และ long.

**Cross-channel (ระวังกลุ่มผู้ฟัง):**
- **ch1 ↔ ch2 เชื่อมกันได้** (ปรัชญา/ธรรมะ = ผู้ฟังทับซ้อน): ใส่ท้ายคำอธิบาย + pinned comment
  ว่า "ช่องพี่น้อง: <ลิงก์>".
- **ch4 (ดราม่า) อย่าไปโปรโมตธรรมะ** — คนละกลุ่ม; ให้ funnel ch4 Shorts → ch4 long series เท่านั้น.
- **Community tab:** `UNKNOWN` ว่าทั้ง 3 ช่องมีแท็บนี้หรือยัง (ต้องเช็คใน Studio; เกณฑ์เปิด
  ไม่ชัด) — ถ้ามี ให้โพสต์ลิงก์ compilation.
