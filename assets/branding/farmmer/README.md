## ติดตั้งภาพปกเองไม่ได้ — ติดที่การยืนยันตัวตน (ต้องให้ K ทำ)

กดปุ่ม "อัปโหลดไฟล์" ใน Studio แล้วขึ้นไดอะล็อก **"สร้างประวัติของช่อง"**
ทุกครั้ง ลิงก์ในไดอะล็อกไปที่ `support.google.com/youtube/?p=rfa_no_idv`
= ต้อง **ยืนยันเบอร์โทร** (ขั้นกลาง) ก่อน ช่องนี้ยังไม่ผ่านขั้นนั้น
แม้หน้า "การมีสิทธิ์ใช้ฟีเจอร์" จะขึ้นว่า "ภาพปกวิดีโอที่ทำเอง เปิดใช้แล้ว"
แต่ในทางปฏิบัติปุ่มยังไม่ทำงานจนกว่าจะยืนยัน

ทางแก้ 2 ทาง (K เลือก):
1. **ยืนยันเบอร์โทร** ที่ youtube.com/verify → ปลดล็อกทันที (ทำครั้งเดียว)
2. ปล่อยให้ช่องสะสมประวัติสักระยะ แล้วปุ่มจะค่อย ๆ ใช้ได้เอง

หลังยืนยันแล้วติดตั้งภาพปกได้ 2 ทาง: อัปโหลดใน Studio (ปุ่ม "อัปโหลดไฟล์"
จะเปิดหน้าต่างเลือกไฟล์) หรือใช้ YouTube Data API `thumbnails.set` — แต่ตอนนี้
Data API ของโปรเจกต์ **โควต้าหมด (403 quotaExceeded)** รอรีเซ็ต

## ทำซ้ำ / ทำช่องอื่น

```
python3 scripts/make_branding.py \
  --banner-art <ภาพดิบ> --avatar-art <ภาพดิบ> --out-dir <โฟลเดอร์ออก> \
  --title "Farmmer" --subtitle "ธรรมะก่อนนอน" \
  --tagline "วางความทุกข์ไว้ตรงนี้ แล้วพักใจให้สบาย"

python3 scripts/make_thumbnail.py --art <ภาพดิบ> --out <ออก.jpg> \
  --line "หยุดคิด" --line "แล้วพักใจ"
```
