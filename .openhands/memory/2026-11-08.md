### Root cause (measured, not guessed)
The dharma 120-minute file's `averageViewDuration` = **379 s = 5.2%** of its length.

never changes. YouTube reads a static-image-plus-narration file as low-effort,
reused content. The problem is the format; the narration was never the issue.

1. a spoken **hook** in the first ~20 s,

   shorter file raises %AVD at once,
3. **change the picture per chapter** (every 3–5 min), not one card for hours,
4. do **not** pump 8–10-hour loops: that risks a Reused Content rejection at YPP.

## 🔁 "การทำงานที่ไม่ต้องพึ่ง K คือออโตเมชันที่สมบูรณ์" (K's message)

K's definition of done: nothing waits for a person to press a button. Audited the
whole rail set against that and found two real holes and one test hole.

**Holes found (measured, not assumed):**
- `studio-ai` and `fetch-music` had **only a GitHub `schedule`** — no driver. GitHub's
  cron is unreliable here (the */30 foreman cron fired once in 30 runs), so a
  schedule-only rail can be missed for days. studio-ai is the learning brain that
  reads Analytics and tells grow-shorts-pool what to make next; fetch-music keeps the
  Shorts bed supplied. Both now have foreman rules (daily / weekly).
- **5 of 8 guard tests had no CI caller** (channel identity, chapter renderer, music
  beds, remake rail, Short art/music). Only test_night, test_publish_shorts_cap and
  test_watchdog ran, each inline in its own rail. A regression in those five would
  never fail a job. New `selftest.yml` runs the whole suite; foreman drives it daily.
  CI run **42439933204 = success, 8/8 passed** (measured, not claimed).

**Guard against recurrence:** `test_watchdog.py` now asserts that every workflow
except `foreman` and `watchdog` is named in `foreman.py`. A future schedule-only rail
fails the test instead of silently never running.

**The principle, distilled:** "complete automation" is not "every workflow has a
cron". It is (a) a reliable driver — the self-chaining watchdog + the foreman — plus
(b) a guard that forces every new rail to be drivable. Quick check:
`python3 scripts/foreman.py --dry-run`.
