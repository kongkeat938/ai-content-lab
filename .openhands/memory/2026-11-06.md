## 🛠️ Channel admin — built + measured (2026-11-06, K: "เอาไปเป็นแอดมิน คุมช่อง ดันโพสต์ ตอบโพสต์")
- **Aider = code tool, NOT a channel admin** (cannot log in to YouTube). The real admin = YouTube Data API + the
  env tokens, in `scripts/channel_admin.py`. Commands: `status`, `latest --limit N`, `comments`, `draft`, `reply`.
- **Measured live:** `status` + `latest` work on all 3 channels today. **`comments`/`reply` → 403 insufficient
  scopes** — tokens have `youtube.upload`+`youtube.readonly` only; comments need **`youtube.force-ssl`**.
- **Owner does once:** `python3 scripts/yt_auth.py --scopes force-ssl --loopback --slug {genx|dharma|kongkeat}`
  (added `--scopes` + `SCOPE_SETS` to yt_auth.py). Then comment read/reply works. **Pinned comments = Studio-only,
  no API** → never automatable.
- **Aider honesty (for the record):** asked twice to add `latest` to the real file — both free models **printed a
  diff but did NOT write the file**, and once hit the context limit. Works on tiny scratch files; not trustworthy
  on real repo files without review.
- Doc: `docs/CHANNEL-ADMIN-2026-11-06.md`.
