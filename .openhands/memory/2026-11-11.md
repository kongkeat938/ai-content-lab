## Bug 1 — the tension hint was keyed to a name nobody used
- `studio_ai.TOPICS_HINT` was keyed `"kongkeat"`, but `question_for()` is always called with the
  Studio id `"ch4"` (main → `question_for(args.channel)`). So the hint never reached the panel.

  the generator (`gen_short_scripts` `require=_TENSION`) drops them anyway, and `test_pace`
  (the guard) went red. **The bug survived because the guard only checked the *file*, not the
  wiring that produces it.**
- Fix (`scripts/studio_ai.py`): key the hint `"ch4"`, resolve names **both ways** via
  `channel_names()` (ch4 ↔ kongkeat-story ↔ kongkeat), add `required_hook()` (reads the
  generator's own rule instead of a 3rd copy), `fallback_topics()` + `filter_topics()` so a
  rule-bound channel's file is never written with off-rule (or empty) subjects.
- New guard `scripts/test_insights_wiring.py` (deterministic, no LLM): the hint reaches the
  prompt, off-rule subjects are dropped, an all-flat answer falls back, a channel with no rule
  is untouched. **Proved it FAILs on the pre-fix code** (git stash) — 3 checks red.
