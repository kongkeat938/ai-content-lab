## ⚠️ Blockers found (important)
- **Custom thumbnails are gated on identity verification.** Clicking "อัปโหลดไฟล์"
  in Studio always raises the "สร้างประวัติของช่อง" dialog; its link is
  `support.google.com/youtube/?p=rfa_no_idv` → **phone verification** is needed.
  The Features page says "ภาพปกวิดีโอที่ทำเอง เปิดใช้แล้ว" but the button still
  won't open a file chooser. **K must verify a phone** (or wait for channel
  history). Then install via Studio or API `thumbnails.set`.
- **YouTube Data API quota exhausted** — every refresh token returns 403
  `quotaExceeded` on `channels?mine=true` (tokens themselves are fine; the token
  endpoint returns scope youtube). Wait for the daily reset. This also blocks
  identifying which env token maps to which channel.
- **Gemini-over-CDP stale-image trap (fixed):** the tool used to pick the first
  `gemini.google.com` tab (often `/u/2/`, a different account) and return the
  OLD image. Fixed: prefer the `/app` tab (no `/u/N/`), wait for the image
  COUNT to grow, and click the LAST download button.

## Round 2 — "ak ทำให้เลยสิ kทำไม่เป็น" (autonomous path)
The pod had been recycled: the Chromium profile at `~/.chromium-profile` was
gone, so the YouTube Studio login died (workspace files survived — only `$HOME`
was reset). Chrome/CDP was restarted with `scripts/start_novnc.sh` but the login
was gone, so Studio UI was off the table.

**What works without a browser: the YouTube Data API.**
- `thumbnails.set` has its **own** daily quota (100 calls), separate from the
  10,000 units the rest of the API shares — but it still hit `403 quotaExceeded`
  because the project-wide quota was already spent. Resets at **midnight
  Pacific = 08:00 UTC**.
- Credentials are now **repo secrets**: `YT_CLIENT_ID`, `YT_CLIENT_SECRET`,
  `YT_CH2_REFRESH_TOKEN` (set via the Actions secrets API, sealed-box encrypted
  with PyNaCl; `nacl.public.SealedBox`, not `SecretBox`/`Box`).
- `scripts/set_thumbnails.py` sets every entry of `content/ch2_thumbnails.json`
  (video_id → image). `--dry-run`, `--check`, `--only`. Quota is treated as a
  *deferral*, not a failure, so CI stays green and the next run finishes it.
- `.github/workflows/set-thumbnails.yml` runs it at 08:07/09:07/10:07/11:07 UTC
  (retry window after the reset) and on manifest/image changes.
- **Proof it works:** a dispatched run authenticated and reached YouTube —
  `_qOSft3tzJ8: FAIL (403 quotaExceeded)` etc. Only quota blocked it. After the
  08:00 UTC reset it will install all six by itself.

**Video ids:** `9bytRcx7SaY` and `Mv0jl7KhxIE` are **not** live — the first 404s
at every thumbnail size; the second 401/403s on oEmbed. Do not trust the id list
in old notes. Six live long videos have covers in
`assets/branding/farmmer/thumbs/`.

**YouTube throttles the pod IP:** after a few fetches, the RSS feed 404s and
oEmbed 401/403s for a while. Space out those calls or do them from PC1.

## Lesson
When Studio UI needs a human and the browser login is gone, do not ask K to log
in — the Data API does the same job unattended once a refresh token is a secret.
