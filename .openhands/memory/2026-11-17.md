## 2026-11-17 (f) — SHIPPED: real b-roll + designed card = the new ch4 format
- **Iterated a vision grader (`gemini-3.5-flash-lite`) on the same 3-beat clip:**
  cold AI landscape **3/10 "cannot pass"** -> raw stock + floating text **4-5/10 "generic
  stock slop"** -> **+ warm grade + frosted-glass card 7/10 production, 8/10 Thai acceptance,
  verdict "escapes stock slop; looks intentional."** That is the standard now.
- **The grader's levers that worked, in order:** (1) a cohesive warm grade over EVERY clip so
  the stock reads as one story; (2) a "signature UI" container — frosted rounded panel,
  hairline border, amber accent bar — not a plain black box and not floating outlined text.
  The grader oscillates on typography ("ditch the box" then "ditch the yellow text"); the
  thing it rewards consistently is *deliberate* design, so stop chasing its wording.
- **BUG (measured, fixed):** the card is one still fed to a `fade` filter; WITHOUT `-loop 1`
  on the card input the fade blanks it after ~0.5 s, so **beats 2..N rendered textless** — only
  beat 1 kept its card. Loop the card input. Guard = `test_qa_video.py` samples a LATE frame
  (2.5 s) and requires the text is still there (mutation: drop the loop -> FAIL).
- **New code:** `fetch_broll.py` (keyless Coverr search/pick/download/attribution; 1080p
  mp4; filter drops premium/vertical/AI/short/long/low-res); `make_kinetic_video.py --broll`
  (real clips as the base, graded+drifted, captions burned over); `build_night.py --broll`
  (fetches one clip per beat, writes `broll.json`; a beat that cannot be sourced FAILS the
  build — no still into a live-action set). Guards: `test_broll.py`, `test_kinetic_broll.py`
  (both mutation-tested). ch4-longform.yml switched from `--chapters --image-style photoreal`
  to `--broll`.
- **edge-tts Thai gives NO word timings** (only SentenceBoundary), so word-by-word karaoke is
  not possible for free; captions are per-line via the kinetic engine's own timing.

  `make_qa_video.build()` had `elif broll and not os.path.exists(clip)` — on a
  *second* run the cached clip already exists, so the branch was skipped and
  `got_clip` stayed False → the beat silently rendered as a STILL (run 2: 3 of 4

  when the fallback is a *different medium* (still vs footage) — the cache hit must
  reproduce the same output, not a downgrade.

## 2026-11-17 (i) — quality pass: "คมชัด" (sharp), not "ขุ่นมัว" (muddy)
K's standing bar = 10/10 on EVERY upload; the first 1080p-able cut was rejected as
"ไม่คมชัด ขุ่นมัว". Panel (`advise.py`, 4/5) + a vision rubric converged on the real wins;
landed + guarded all of them.
- **Sharpness root cause (measured, not the grader):** the b-roll drift upscale softened the
  picture — native centre LapVar 119 vs **88 at 1.12x**; lanczos 95.7 vs bicubic 87.6. FIX:
  **1.06x lanczos** (`BROLL_ZOOM`, `broll_chain()` now takes the clip). Guard `test_qa_video.py`
  #8 renders a band-limited frame native vs through the chain and requires ≥65% detail;
  **mutation-tested: 1.30x → FAIL 47%**. (A pure `testsrc2` is near-Nyquist and unfair — blur
  it with `gblur=sigma=2` first so it behaves like footage.)
- **Brightness:** stock clips vary a lot (cat luma **107** vs sky **176**) → dark beat reads
  muddy next to a bright one. FIX: `broll_gamma()` measures each clip and gamma-lifts toward
  **150** (capped 1.55; a bright clip untouched). Guard #9: synthetic dark clip must lift
  ≥25, bright clip must NOT be lifted. Rendered beats now 138–176.
- Also: **1080p crf18** (was 720p), **floating Thai text** (Kanit + dark stroke + shadow, no
  boxes), wrapped long question+answer into safe area.
- **The vision grader is non-deterministic:** the SAME 1080p cut scored **9/10 then 5/10** on
  two runs (flip-flops 5↔9 across the session). Panel (3/5, gemini 429) unanimous: **never
  gate the grader in CI**; judge by technical metrics + fail-able guards. Verified the grader
  is NOT wired into any workflow/test (ad-hoc only) → already compliant. Recorded in
