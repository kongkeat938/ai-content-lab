## stdin/SIGTTIN freeze — root cause measured (session 2)

**Problem:** `scripts/test_publish_motion.py` never finished (rc=124 at 400 s), and the
publish-motion rail would freeze the same way.

**Cause (measured, not guessed):** `subprocess.run(...)` inherits stdin. ffmpeg (loudness
probe) and git then read the TTY; a child that reads a TTY it does not own is **stopped by
SIGTTIN**, which suspends the whole process group. Proof: `ps -eo pid,ppid,stat` showed
`123008 TN do_signal_stop` with child `123051 ffmpeg ... -af ebur128` also `TN` — stopped,
not CPU-bound; faulthandler never fired. Same ffmpeg command with `< /dev/null` → rc=0 in
0.3 s. The first fix (publish_motion.py only) was incomplete: the freeze moved into
`short_standard._loudness`, which is the shared gate.

**Solution:** `stdin=subprocess.DEVNULL` on every subprocess call in the affected files, plus
a ratchet guard so new code cannot add a bare call.

**Files changed (each has a Gemini APPROVE in `docs/reviews/ledger.json`):**
- `scripts/short_standard.py` — `_probe`, `_loudness` (the real culprit)
- `scripts/make_short.py` — 3 calls (voice/loudness source)
- `scripts/publish_motion.py` — 5 calls (2 ffmpeg + 3 git)
- `scripts/test_publish_motion.py` — `sh()` + new check 7
- `scripts/test_subprocess_stdin.py` (new) — AST ratchet vs `docs/subprocess_stdin_baseline.json`

**Verify:** `test_publish_motion.py` PASS in ~20 s **on a live TTY** (was: frozen
indefinitely). Ratchet proven to FAIL by injecting a bare call into a clean file
(`yt_duration.py`) and by adding a brand-new file with one bare call; both restored → PASS.
Suite: 9/9 PASS.

**Panel decision (Gemini):** option (B) — do not fix all 33 remaining files now (CI stdin is
not a TTY, so SIGTTIN cannot fire there); guard new calls and fix files as they are touched.
Debt recorded: **92 bare calls in 34 files**, visible on every run.

**Trap for the next session:** a "hung" rail at state `TN`/`TNl` is **stopped by SIGTTIN**,
not deadlocked. Check `ps -eo pid,ppid,stat,wchan` before theorising about contention.
Also: two Gemini reviews of the new guard hallucinated code that was not in the file — a
canary that asks for a verbatim quote of a *specific* line catches that; a vague canary does not.
