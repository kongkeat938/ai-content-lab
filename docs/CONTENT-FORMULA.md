# สูตรสร้างคลิป — คัดกรองบทด้วย AI หลายตัวก่อนสร้าง

คำสั่ง K (2026-11-04): "ในการสร้างคลิปให้สร้างสูตร ใช้ ai หลายตัวคัดกรองบท เนื้อหา
จนเรียบเรียงว่าดีที่สุดก่อน จากนั้นค่อยนำไปสร้าง"

## สูตร (pipeline)

```
1. ร่าง     Gemini (gemini-3.5/3.1-flash-lite) เขียนสคริปต์ตามกติกาฮุกของช่อง
   ↓
2. คัดกรอง panel หลายตัว  ──  gemini-3.1-flash-lite
   │                          gemini-3-flash-preview
   │                          gemini-3.5-flash-lite
   │                          pollinations (ถ้าว่าง)
   │  แต่ละตัวให้คะแนน 0-100 + ชี้จุดอ่อน + เสนอฉบับแก้
   ↓
3. เลือก     เอาฉบับที่คะแนนสูงสุด + ผ่านกติกา (valid) → เขียนทับร่าง
   ↓
4. ทำซ้ำ 2 รอบ (rounds=2) จนคะแนนไม่ขึ้น
   ↓
5. สร้าง     edge-tts/gTTS + ffmpeg → คลิป
```

## หลักการที่ทำให้เชื่อถือได้

- **หลายโมเดล ไม่ใช่โมเดลเดียวตรวจตัวเอง** — จุดบอดของตัวหนึ่งถูกจับโดยอีกตัว
  (วัดจริง: รอบ 1 คะแนน 65 → รอบ 2 คะแนน 92; โมเดลที่เขียนไม่ใช่ตัวที่ให้คะแนนสูงสุดเสมอ)
- **กติกาฮุกมาจากข้อมูลจริงของช่อง** ไม่ใช่ความเห็น AI — panel ถูกบอกว่า
  "ฮุกแบบไหนได้ 300-570 วิว/วัน" ก่อนให้คะแนน (ดู `docs/HOOKS-MEASURED.md`)
- **ทุกโหวตถูกเก็บ** ใน `<input>.panel.json` → ตรวจย้อนได้ ไม่ใช่กล่องดำ
- **ผู้ตรวจล่มตัวใดตัวหนึ่งไม่หยุดงาน** — vot ลด แต่รอบยังเดิน (Gemini 503 บ่อย)
