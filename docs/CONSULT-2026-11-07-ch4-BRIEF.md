## การวิเคราะห์เชิงจิตวิทยา (ให้ที่ปรึกษาตรวจ/แย้ง)

1. **Expectancy violation (ฝ่าฝืนความคาดหวัง):** ชื่อสัญญา 3 อย่าง — (ก) เป็นการ์ตูน
   (ข) สำหรับเด็ก (ค) สนุก/ตลก. เนื้อหาจริงให้ (ก) เสียงผู้ใหญ่พูดช้า (ข) เรื่องเศร้า/คิดถึงบ้าน
   (ค) 30 นาที ไม่มีการเคลื่อนไหว. → คนคลิกเจอ "ผิดสัญญา" → bounce ใน 5–15 วิ → ส่งสัญญาณ
   "ไม่น่าสนใจ" กลับ YouTube → ลดการแนะนำ (negative feedback loop).

2. **Audience self-selection mismatch (กรองกลุ่มผิดทั้งสองทาง):**
   - เด็ก/ผู้ปกครองคลิก: เจอเสียงผู้ใหญ่ช้า ๆ ไม่มีการเคลื่อนไหว → ออกทันที
     (เด็กต้องการ stimulation/การเคลื่อนไหวสูง)
   - ผู้ใหญ่ที่อยากฟังเรื่องอบอุ่นใจ: เห็นชื่อ "การ์ตูน" → คิดว่า "ของเด็ก" → ไม่กล้าคลิก
     (social identity — ผู้ใหญ่ไม่อยากดู "การ์ตูน")
   → **คนผิดเข้ามา + คนถูกไม่เข้ามา** = แย่ทั้งสองด้าน

3. **Category/algorithm mismatch:** YouTube จัดหมวดตามชื่อ+คำค้น+พฤติกรรม. ชื่อ "การ์ตูน" +
   tags "เด็กและครอบครัว" → ระบบเข้าใจว่าเป็นช่องเด็ก → แสดงกับ cohort เด็ก → CTR ต่ำ
   (เด็กไม่คลิก 30 นาที) + retention ต่ำ → algorithm ลด reach.

4. **จิตวิทยาของชื่อช่อง:** ชื่อ = 3 cue พร้อมกัน — category cue, audience cue, emotional cue.
   ถ้าทั้ง 3 ผิด → ผู้ชมที่ใช่กรองตัวเองออก. ชื่อที่ตรงควรบอก (ก) เนื้อหาคืออะไร (ข) ใครควรดู
   (ค) ได้อารมณ์อะไร. เนื้อหาจริง = nostalgia + parasocial comfort สำหรับผู้ใหญ่วัย 30–60 →
   cue ที่ตรงคือ "ความอบอุ่น / ความทรงจำ / คิดถึงบ้าน / ฟังก่อนนอน" ไม่ใช่ "การ์ตูน".

5. **ต้นทุนการเปลี่ยนชื่อ vs ต้นทุนแบกชื่อผิด:** บน YouTube การเปลี่ยนชื่อช่อง **ไม่ลบวิดีโอ
   ไม่ลบผู้ติดตาม** (handle เปลี่ยนได้, subs ยังอยู่). → ต้นทุนเปลี่ยนชื่อต่ำกว่าต้นทุนแบก mismatch
   ที่กัด reach ทุกวัน.

## ทางเลือกที่ต้องให้ที่ปรึกษาชั่ง

- **A. เปลี่ยนชื่อช่อง + realign ทุก cue** (ชื่อ/คำอธิบาย/handle/เพลย์ลิสต์/tags/รูป) ให้ตรงเนื้อหา
  อบอุ่นใจสำหรับผู้ใหญ่
- **B. เปลี่ยนเนื้อหาให้ตรงชื่อ** (ทำการ์ตูนจริง) — แพง, ขัด "free tools only", และข้อมูลวัดบอกว่า
  เนื้อหาความทรงจำครอบครัวคือสิ่งที่ได้ผล
- **C. แยกช่อง** — เก็บ "การ์ตูน" ไว้ทำการ์ตูนจริง (เด็ก) แล้วย้ายเรื่องอบอุ่นใจไปช่องชื่อถูก
- **D. Reposition กึ่งกลาง** — ชื่อที่ครอบได้ทั้งคู่ (ตัดคำ "การ์ตูน" ออก)

## คำถาม (5 ข้อ)
1. วินิจฉัย: ปัญหาหลักคือ "ชื่อช่อง" หรือ "เนื้อหา" หรือ "ทั้งคู่"? อ้างตัวเลข
2. ทางเลือก A/B/C/D ควรเลือกอันไหน เพราะอะไร — และอะไร *ไม่* ควรทำ
3. ถ้าเปลี่ยนชื่อ: ควรใช้ชื่อแบบไหน (เกณฑ์ทางจิตวิทยา) ยกตัวอย่าง 3 ชื่อที่ตรง
4. ลำดับงาน "รื้อทำใหม่" ที่ถูกต้อง (เปลี่ยนอะไรก่อน-หลัง) เพื่อไม่ทำลาย subs/reach ที่มี
5. ตัวชี้วัดที่จะบอกว่าการรื้อสำเร็จ (วัดได้ใน 28 วัน)
