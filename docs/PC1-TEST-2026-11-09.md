## สาเหตุราก (ยืนยันแล้ว)

`config.cmd` เป็นแค่ wrapper ที่เรียก `bin\Runner.Listener.exe`. การ **แตกไฟล์ zip รอบก่อนไม่ครบ**
ทำให้ `run.cmd` + `config.cmd` อยู่ แต่ `bin\` หาย → ตัวเช็คเดิม `Test-Path run.cmd` จึงข้ามการ
ดาวน์โหลด แล้ว `config.cmd` ตายด้วย "The system cannot find the file specified" (exit 1) — ตรงเป๊ะ

พิสูจน์: ดาวน์โหลด `actions-runner-win-x64-2.338.2.zip` (104 MB, 276 entries) → มี
`bin/Runner.Listener.exe` จริง

## แก้แล้วใน `ops/pc1_install_runner.ps1` (commit `2442611`)

- เรียก "แตกครบ" ต่อเมื่อมี **`bin\Runner.Listener.exe`** (ไม่ใช่แค่ run.cmd/config.cmd)
- แตกไม่ครบ → **ดาวน์โหลด zip ใหม่สด ๆ** (zip ที่ถูกตัดครึ่งดูดีตามชื่อ — ลบก่อนโหลด)
- เพิ่ม `-Clean` สำหรับลบ `C:\actions-runner` แล้วเริ่มใหม่หมด
- **echo output ของ config.cmd** → ล้มเหลวครั้งหน้าจะบอกสาเหตุเอง ไม่ใช่แค่ "exit 1"

ตรวจสอบ: parse ผ่านด้วย pwsh 7.4.6 · unit-check logic partial/complete → ถูกต้อง
