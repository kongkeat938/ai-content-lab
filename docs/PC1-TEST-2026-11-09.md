## ผลการทดสอบ — PC1 ออนไลน์ แต่ **ขับไม่ได้** จาก pod

รัน `python3 ops/check_pc1.py` (4 เส้นทาง):

| เส้นทาง | ผล | ความหมาย |
|---|---|---|
| tailnet `/health` | ❌ **HTTP 502** | tailscaled ขึ้น + serve listener มีอยู่ ⇒ **PC1 เปิดอยู่/ออนไลน์** แต่ backend `winremote-mcp` (127.0.0.1:8090) ดับ |
| tailnet `/mcp` tools | ❌ HTTP 502 | MCP handshake ไม่ผ่าน (ตัว backend ตาย) |
| cloud `app.all-hands.dev/mcp/mcp` | ❌ ไม่ใช่ทางไป PC1 | ตอบ 200 ด้วย token แต่ **เป็น MCP ของ OpenHands เอง** (tools = `create_pr`, `create_mr`, `tavily_*`) — ไม่ใช่ทางไป PC1 |
| actions runner | ❌ **0 runners** | ไม่มี runner ลงทะเบียนใน `kongkeat938/ax-workspace` ⇒ งาน `pc1-task` ค้างตลอด |

**สรุป:** PC1 **เปิดอยู่และต่อ tailnet ได้** แต่ทั้งสองช่องทางที่ agent ใช้สั่งงาน — winremote MCP และ self-hosted runner — **ดับทั้งคู่** ⇒ ต้องมีคนรันสคริปต์ซ่อมที่เครื่อง (PC1 อยู่หลัง NAT ไม่มี inbound route)

**ยืนยันเพิ่ม:** `scripts/pc1_health.py --strict` → `backend-down` (exit 1) · DNS `desktop-rgk6jkb.tail8740ad.ts.net` → 103.84.155.153/.217 (Tailscale ingress) · funnel ทุก path (/, /health, /mcp, /sse, /tools) → 502

## แก้ตัวตรวจ 2 จุดที่ "โกหก" (พบตอนทดสอบ)

`ops/check_pc1.py` เดิมรายงานผิด 2 อย่าง ทำให้อ่านสถานะไม่ออก:

1. **`probe_cloud` นับ `app.all-hands.dev/mcp/mcp` เป็นเส้นทางไป PC1** — จริง ๆ มันคือ MCP ของ OpenHands เอง (200 + tools `create_pr`/`tavily_*`) ⇒ เปลี่ยนให้คืน `False` เสมอ + ระบุชัดว่าเป็นแค่ egress
