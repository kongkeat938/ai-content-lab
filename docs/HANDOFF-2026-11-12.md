`element.click()`, a real mouse sequence, and keyboard Enter — none advanced; no
`window.open`, no navigation). This gate needs a genuine user gesture / a real browser

## Thai text rendered as boxes — fixed (2026-11-12)

K saw Thai text as squares ("สี่เหลี่ยม") on the VNC screen. Cause (measured): the base
image ships **only DejaVu** (8 fonts, no Thai glyph); `fc-match sans-serif:lang=th` fell
back to DejaVu. Fix: install `fonts-thai-tlwg` + `fonts-noto-core` (now 64 fonts), restart
chromium. `start_novnc.sh` now installs Thai fonts on the fly and starts chromium with
`--lang=th-TH`. Verified by pixels: rendering `ก` gives a different canvas hash/ink than a
tofu box (`U+E000`) — width alone was misleading (Thai `ก` and the box both measured 24 px).

  401 could have read as a false READY). It now exchanges the alt token with
  `YT_ALT_CLIENT_ID`/`YT_ALT_CLIENT_SECRET` (client B) first, and requires a real
  `access_token`. Secrets added: `YT_ALT_CLIENT_ID`, `YT_ALT_CLIENT_SECRET`.
