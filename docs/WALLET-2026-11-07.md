# วอลเล็ตอยู่ไกลแค่ไหน — วัดจริง 2026-11-07

K: "เราแค่ไปเอาอัลกอริทึมที่เราต้องการมาไว้ในบัญชีเรา วอลเล็ตเราแค่นั้นเอง"

เอกสารนี้ตอบด้วยตัวเลข ไม่ใช่ความเห็น. ทุกค่ามาจาก `scripts/analytics.py`
(YouTube Analytics API = watch time จริง) และหน้า channel สาธารณะ (subscriber count).

## 1. วอลเล็ต = YouTube Partner Program (YPP)
เกณฑ์: **1,000 subscribers + 4,000 watch-hours ใน 12 เดือน** (หรือ 10M Shorts views/90 วัน)

## 2. สถานะจริง (28 วัน, 2026-10-10 .. 11-07)

| ช่อง | subs | watch-h /28d | ถึง 1,000 sub | ถึง 4,000 h ที่ความเร็วนี้ |
|---|---|---|---|---|
| ตาต้า GenX | **150** | 68.3 | 15% | **~4.5 ปี** |
| Farmmer (dharma) | 43 | 50.2 | 4% | ~6.1 ปี |
| เรื่องเล่าการ์ตูน | 10 | 16.1 | 1% | ~19 ปี |
| **รวม** | **203** | **134.6** (4.81 h/วัน) | 20.3% | — |

## 3. ข้อสรุปที่สำคัญ (และโหด)
**การเดินแบบเดิมไปไม่ถึงวอลเล็ต.** ผลรวมทั้ง 3 ช่อง = 134.6 ชม./28 วัน = 4.81 ชม./วัน.
ต้องได้ 4,000 ชม. → ที่ความเร็วนี้ใช้เวลา **หลายปี**. การเพิ่มจำนวนคลิปทีละนิดไม่พอ.

## 4. "อัลกอริทึมที่เราต้องการ" = อัลกอริทึมที่ทำให้ watch time ต่อคลิปสูง
ตัวขับเคลื่อนรายได้ไม่ใช่จำนวนคลิป แต่คือ **watch time ต่อการมองเห็น 1 ครั้ง**:
- **Retention (% ที่ดูจนจบ)** — ยิ่งสูง YouTube ยิ่งดันต่อ
- **Hook 30 วินาทีแรก** — ตัวชี้ขาดว่า YouTube จะขยายการทดลองหรือหยุด
- **CTR thumbnail/title** — ตัวคูณที่ทำให้คนเข้ามาดู

**หลักฐานในข้อมูลเราเอง:** GenX มี **150 subs จาก Shorts** แต่ได้แค่ **1.71% ของเป้า watch-hours**.
→ **Shorts ให้ sub แต่ไม่ให้ watch-hours.** watch-hours มาจาก **long-form ที่คนดูจนจบ** เท่านั้น.
→ อัลกอริทึมที่ต้อง "เอามาไว้ในบัญชี" = **long-form retention** ไม่ใช่ปริมาณ Shorts.

## 5. คันโยกเดียวที่ต้องดึง (ทำได้ด้วยเครื่องมือฟรีที่มีอยู่แล้ว)
1. **long-form 1 คลิปที่ retention สูง** ชนะ Shorts 100 คลิป (เพราะ YPP นับชั่วโมงดู)
2. วัด avg % viewed ต่อคลิป → ตัวไหนเกิน 100% (คนดูวนซ้ำ) = ตัวที่อัลกอริทึมชอบ → ทำซ้ำสูตรนั้น
3. ตัวเลขทั้งหมดวัดได้ฟรีผ่าน `scripts/analytics.py`

## 6. บทเรียน
"เอามาไว้ในบัญชีเรา" ไม่ใช่เรื่องขอความช่วยเหลือจากใคร — เป็นเรื่อง **เขียนให้ถูกตามอัลกอริทึม
ของแพลตฟอร์ม** (retention + hook + long-form) แล้วเครื่องมือฟรีที่มีอยู่ก็พาไปถึง.
สิ่งที่ขาดไม่ใช่เครื่องมือ แต่คือ **คลิปที่คนดูจนจบ**.

## 7. "ตัวแปลงเป็นรายได้" เอามาได้ยัง? (ตอบ 2026-11-07)

**ยังไม่ได้ — และ "ตัวแปลง" ไม่ใช่สิ่งที่โหลด/ขอมาได้** มันคือ **คุณสมบัติ (eligibility)** ที่ YouTube เปิดให้
เมื่อเราถึงเกณฑ์. อ่านกฎทางการ (support.google.com/youtube/answer/72851, อ่าน 2026-11-07):

| ต้องมี | สถานะเรา |
|---|---|
| 1,000 subs | **203 / 1,000 = 20.3%** |
| 4,000 qualified watch-hours / 12 เดือน | **134.6 / 4,000 = 3.36%** (ต่อ 28 วัน) |
| หรือ 10M qualified Shorts views / 90 วัน | ไกลมาก |
| 2-Step Verification เปิด | ต้องเช็คที่บัญชี |
| advanced features | ต้องเช็ค |
| AdSense for YouTube ผูกแล้ว | **ยังไม่มี** |
| ไม่มี strike | สะอาด |

**ข้อเท็จจริงชี้ขาด:** *watch hours จาก Shorts Feed **ไม่นับ** เข้า 4,000 ชั่วโมง*
→ ช่องที่โตด้วย Shorts (GenX 150 subs) **ไม่ขยับเพดาน watch-hours เลย**

**สรุป:** "ตัวแปลงรายได้" = **ผลลัพธ์ ไม่ใช่เครื่องมือ** เอามาไว้ในวอลเล็ตได้ทางเดียวคือ
**ผ่านเกณฑ์ 1,000 subs + 4,000 ชั่วโมงดู** ด้วย long-form ที่คนดูจนจบ. ยังต้องทำอีก ~3,865 ชั่วโมง.
