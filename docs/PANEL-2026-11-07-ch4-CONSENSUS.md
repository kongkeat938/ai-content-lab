## การวิเคราะห์เชิงจิตวิทยา (ที่ panel เห็นตรงกัน)

1. **Expectancy violation** — ชื่อสัญญา "การ์ตูน/เด็ก/สนุก" แต่ของจริงคือเสียงผู้ใหญ่เล่าเรื่องช้า
   + ภาพนิ่ง → คนคลิกเจอ "ผิดสัญญา" → bounce ใน 5–15 วิ → YouTube ลด reach (negative loop)
2. **Self-selection สองทางพัง** — เด็ก/ผู้ปกครองเข้ามาแล้วออก (ไม่มีการเคลื่อนไหว) และผู้ใหญ่ที่อยากฟัง
   เรื่องอบอุ่นเห็นคำ "การ์ตูน" แล้วไม่กล้าคลิก (social identity: ผู้ใหญ่ไม่อยากดู "การ์ตูน")
   → **คนผิดเข้า คนถูกไม่เข้า**
3. **Algorithm misclassification** — ชื่อ+tags "เด็กและครอบครัว" → ระบบจัดเข้าหมวดเด็ก → แสดงกับ cohort เด็ก
   → CTR/retention ต่ำ → reach ต่ำ
4. **ชื่อช่อง = 3 cue พร้อมกัน** (category / audience / emotional) ถ้าผิดหมด คนที่ใช่จะกรองตัวเองออก
5. **ตัวเลขชี้ขาดของ DeepSeek:** ภายในชื่อช่องเดียวกัน (คงที่) Shorts "ครอบครัวเจาะจง" = 460–1,083 วิว
   แต่ "นิทานคลาสสิก" = 1–6 วิว → **ต่าง ~500 เท่า** → ตัวขับหลักคือ *ความเข้ากันของเนื้อหา* ไม่ใช่ชื่อ
   แต่ชื่อทำงานเป็น "เพดาน + ตัวกรองกลุ่มผิด" → แก้ทั้งคู่ โดย **เนื้อหาก่อน (ฟรี ทันที) แล้วปิดด้วยชื่อ**
6. **subs ต่อ 1,000 วิว:** ch4 = 1.93 < dharma 2.92 < genx 5.36 → ch4 แย่สุด สอดคล้องกับวิว/watch-hour
