# pollinations

**สรุป**

1. **วินิจฉัย** – ใช่, ค่ามาตรฐาน `per‑run=0` ทำให้ทุก Short มี 0 view จึงเป็นสาเหตุหลักของ median ต่ำ  
2. **89 คลิปที่ยอด 0** – ถ้าไม่มีแปลงคะแนนหรือเรื่องใหม่ที่ดึงดูด, เน้นเวอร์ชันที่มี engagement (หรืออัพโหลดใหม่หลัง tweak) แทนการปล่อยมีความเสี่ยง  
3. **โพสต์** – แนะนำ 3‑5 Shorts ต่อวัน (2‑3 ครั้งทุกวาน), ให้เวลาวิเคราะห์และปรับโครงสร้างสั้น ๆ ก่อนเพิ่มจำนวน  
4. **หยุดทันที** – ปิดสคริปต์ `per-run=0`, ตั้งค่า “viewer‑boost” หรือ “like‑gain” เพื่อให้ Shorts ไม่ได้ “เดินเพียงแต่อย่าโพสต์ 89 ชิ้นที่หมดหวัง”  

เมื่อแก้ไขอัลกอริทึมให้ได้เรียบร้อย, เก็บปริมาณที่กระทั่งคุณคั่น (3-5/วัน) จะช่วยให้ median ค่อยขึ้นและไม่ได้สูญเสียทรัพยากร.
