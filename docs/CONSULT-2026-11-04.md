## คำตอบที่ได้ (และ ak ตรวจซ้ำเอง)

### P1 — thumbnail
- **ChatGPT: "ไม่มีทาง bypass ที่ถูกกฎ"** — YouTube บังคับ verification จริง. 3 ทาง: (a) รอ channel history, (b) **ยืนยันเบอร์ครั้งเดียว**, (c) ใส่ artwork ในเฟรมแรกของวิดีโอ.
- **Gemini:** เหมือนกัน — bake title card เป็นเฟรมแรก + ให้ auto-thumbnail ของ YouTube เลือกเฟรมที่คม.
- **สรุป ak:** ไม่มีทางลัดที่ถูกกฎ. ที่ทำได้เองตอนนี้ = **ออกแบบเฟรมแรกให้เป็น title card** (ทำได้ทันที ไม่ต้อง K).

### P2 — รูปฟรี
- **ChatGPT (เรียงลำดับ):** (A) รัน open model local (ComfyUI — ต้อง GPU), (B) **Python + SVG + Pillow** (ดีที่สุดสำหรับ server), (C) stock ฟรี — **Wikimedia Commons / Pexels API**.
- **Gemini:** Hugging Face serverless (ต้อง token) หรือ kinetic typography ด้วย ffmpeg.
- **ak ตรวจซ้ำเอง:** Pollinations image ยัง 503, HF ต้อง token. ⇒ **ทางที่ใช้ได้จริงตอนนี้ = SVG/Pillow + Wikimedia Commons** (มีอยู่แล้ว) **+ Pexels API** (มีคีย์บน PC1).

### P3 — เพิ่ม watch time
- **ChatGPT:** อย่าไปยึด thumbnail สำหรับ Shorts; **ย้ายบางส่วนไป long-form**.
- **Gemini:** (1) **loop hook ให้จบต่อต้น** (avg% > 100%), (2) อัด 3–5 Shorts/วัน, (3) cross-post TikTok/FB.
- **ak:** ตรงกับที่วัดเอง — **loop = คันโยกอันดับ 1** (คลิป avg% > 100% เก็บ watch-hour สูงสุด).

## ข้อสรุป: ใครเป็นที่ปรึกษา

- **ที่ปรึกษาหลัก = ChatGPT** — ตอบ actionable + ยืนยันข้อจำกัดตรงกับความจริง (no thumbnail bypass), เสนอ hybrid image ที่ server ทำได้. เข้าถึงผ่าน Chrome PC1.
- **ที่ปรึกษารอง (automatable) = Gemini API** — เรียกจาก pod ได้ตรง ๆ ใช้เป็นตัวตรวจ/ร่างได้ทันที.
- DeepSeek/Devin ยังไม่พร้อม (ล็อกอิน/คีย์ตาย).

## อัปเดต 2026-11-04: K ยืนยันเบอร์ + ยืนยันขั้นสูงแล้ว
- **API ตรวจแล้ว:** `longUploadsStatus=allowed` ทั้ง 3 ช่อง · avatar + banner ตั้งแล้ว · thumbnail ch2 **ทั้ง 7 ตัว live อยู่แล้ว** (ทาง Data API ไม่ต้องพึ่ง verification อยู่แล้ว).
- **ช่องว่างจริง = SEO:** ทุกช่อง `channel.keywords` ว่าง → ใส่แล้วทั้ง 3 ช่องผ่าน `scripts/set_channel_seo.py` (เขียนจริง + อ่านกลับยืนยัน).
- ⇒ **P1 ปิด**: ไม่มีงานค้างที่ต้องรอ K เรื่อง thumbnail/verification อีก.
