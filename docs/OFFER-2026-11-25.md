## 5. ทำไม ak ส่งเองไม่ได้ (ข้อจำกัดจริง)

1. **YouTube ไม่มี API สำหรับส่งข้อความส่วนตัว** — DM ทำผ่าน API ไม่ได้เลย
2. **การคอมเมนต์ต้องมี scope `force-ssl`** ซึ่ง token ปัจจุบันไม่มี (บันทึกไว้ใน memory: "Comment writes need force-ssl")
3. **การคอมเมนต์ชวนขายบนช่องคนอื่น = ความเสี่ยงสแปม** ทั้งต่อบัญชีผู้ใช้และต่อช่องของเรา → ไม่ควรทำแม้มีสิทธิ์

**วิธีที่ควรทำ:** เปิดหน้า About ของแต่ละช่อง → คัดลอกอีเมลธุรกิจ (ช่องใหญ่ส่วนใหญ่เปิดไว้) → ส่งข้อความในหัวข้อ 2 ทีละช่อง (ปรับชื่อช่อง) → บันทึกว่าใครตอบใน `content/outreach_log.json`

ถ้า K ต้องการให้ ak ส่งอีเมลเองได้ ต้องอนุมัติ 2 อย่าง: (ก) เปิด Gmail/SMTP credential (ข) ยืนยันว่าจะส่งในนาม K — ak จะไม่สมัครหรือส่งในนาม K โดยไม่มีการยืนยันซ้ำ

## 6. ตัวชี้วัด + เงื่อนไขหยุด

| ตัวชี้วัด | เป้า 30 วัน | ถ้าไม่ถึง = ทำอะไร |
|---|---|---|
| ส่งข้อความแล้ว | ≥ 12 ช่อง | < 12 = K ไม่มีเวลา → เปลี่ยนช่องทาง |
| ตอบกลับ | ≥ 3 ช่อง (25%) | 0–1 = ข้อความ/ราคาไม่ตรง → เขียนใหม่ 1 รอบ |
| ลองงานฟรี 1 คลิป | ≥ 2 ราย | 0 = ไม่มีดีมานด์จริง → **หยุดขายบริการนี้** |
| งานเสียเงินแรก | ≥ 1 ราย ภายใน 30 วัน | ไม่มี = หยุด แล้วไปทาง affiliate/ช่องตัวเอง |

**เงื่อนไขตัดสินใจ:** ถ้าครบ 30 วันแล้วยังไม่มีงานเสียเงินเลย → หยุดเส้นทาง "รับจ้างตัดคลิป" และย้ายเวลาไปทำช่องตัวเอง/affiliate แทน (อย่าเผาเวลาเพิ่มเกิน 30 วัน)
