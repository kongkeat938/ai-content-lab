# บรีฟที่ปรึกษา — แก้ AVD ต่ำของคลิปยาว (2026-11-07)

## บริบท
ช่อง YouTube ไทย 3 ช่อง (ปรัชญาชีวิต / ธรรมะก่อนนอน / เรื่องเล่าอบอุ่นใจ). เป้า YPP
4,000 ชั่วโมงดู. Shorts Feed ไม่นับ — นับเฉพาะคลิปยาว.

## ตัวเลขวัดจริง (YouTube Analytics, 28 วัน 2026-10-10..11-07)
- รวมทั้ง 3 ช่อง: 36,363 วิว / 162.4 ชั่วโมงดู / subs +145
- **ชั่วโมงดูที่นับเข้า YPP จริง (คลิปยาวเท่านั้น) = 14.4 ชั่วโมง (~9%)** — ที่เหลือ 129 ชม.
  มาจาก Shorts ซึ่งไม่นับ
- คลิปยาวที่ดีที่สุด: dharma 120 นาที (`F4qFHoVpEyI`) = 338 วิว / 13.28 ชม. / **AVD 379 วิ
  = 5.2%** ของความยาว. อีกคลิป 17 นาที = AVD 27.3% แต่ 15 วิวเท่านั้น
- genx มี Shorts 52 ตัว วิวสูงสุด แต่คลิปยาวเพิ่งมี 1 ตัว (30 นาที) ยังไม่มีข้อมูล

## ข้อจำกัดที่ตายตัว
- เครื่องมือฟรีเท่านั้น. ห้าม paid API, ห้าม generative image model ที่ไม่มี fallback
- คลิปยาวตอนนี้ = **การ์ดภาพนิ่งใบเดียว** (การ์ด 1 ใบ + zoom ช้า 3.5% วนซ้ำ 24 วิ)
  ตลอดทั้งคลิป 30–120 นาที — ไม่มีอะไรเปลี่ยนบนจอเลย
- ผู้ฟังเป็นคนไทย วัยทำงาน/ก่อนนอน ฟังเป็นเสียงเป็นหลัก (ไม่จ้องจอ)
- Sandbox/CI เรนเดอร์ ffmpeg; ต้องเรนเดอร์ 30 นาทีได้ใน ~10 นาที

## คำถาม (ตอบเรียงตามผลตอบแทน/แรง)
1. คลิปยาวที่ **ไม่นับเป็นวิดีโอ "ปั้นชั่วโมงดู" แบบ sleep** — AVD 5.2% บน 120 นาที.
   เราควรแก้ **อะไรก่อน** เพื่อดัน AVD ให้คนดูจริง? (format? ความยาว? hook 30 วิแรก?
   จังหวะเปลี่ยนภาพ?) เรียงลำดับเป็นข้อ ๆ
2. **การเปลี่ยนภาพ**ช่วย retention ของคลิปเสียงได้จริงไหม? ถ้าช่วย ควรเปลี่ยนแบบไหน/ทุกกี่วินาที
   โดยใช้ฟรี (เช่น สลับการ์ดทุก 20-30 วิ, Ken Burns, ข้อความขึ้นตามบท) — และมีข้อเสียอะไร
3. **ความยาวที่เหมาะ**สำหรับช่องเสียงภาษาไทยที่ AVD ปัจจุบัน 5%: 10-15 / 20-30 / 60 / 120 นาที?
   ให้เหตุผลจากตัวเลข AVD × ความยาว
4. อะไรที่ **ห้ามทำ** (กับดักที่จะทำให้แย่ลงหรือเสี่ยง TOS)?
5. 30 วันข้างหน้า: 3 อย่างที่ให้ผลมากสุดต่อชั่วโมงดูที่ "นับได้" — เจาะจง
