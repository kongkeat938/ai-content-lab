# Description and tags for long-form (2026-11-06)

The last piece of the long-form SEO pass, after titles and thumbnails.

## The gap, measured

Every changed video had **zero description and zero tags**. The search surface was
completely empty: a description feeds YouTube search and the related-video rail,
and tags disambiguate the topic. Writing `description` and `tags` needs only the
`youtube.upload` scope the tokens already hold -- no new consent, same as the
titles and thumbnails.

## What was built

`scripts/optimize_seo.py` asks the two measured KEEP advisors (gemini, pollinations)
for a 2-3 sentence Thai description (keyword-carrying, 3 hashtags) and a 10-15 item
Thai tag list, per video. It reads the current `snippet` first and writes back title
and categoryId unchanged -- `videos.update` replaces the whole part, so a blind
write would drop the title set earlier.

## How the effect is judged

Same as the rest: re-read at 14 days. The description and tags mostly help the
**search** surface (1.5-2.5% of views today), so the honest expectation is a small
change there, not a spike in the Shorts feed.
