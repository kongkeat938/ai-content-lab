# ให้ ChatGPT บน PC1 ช่วย "เชื่อมเรากลับ" — PCSEV (2026-11-08)

K: *"ChatGPT รีโมท PC1 ได้ ที่เหลือให้เขาช่วยเชื่อมเรา"*

## ปัญหา (Problem) — วัดจริง 2026-11-08

| สิ่งที่วัด | ผล |
|---|---|
| pod browser → Google login | **ถูกบล็อก** — หน้า `signin/rejected` "This browser or app may not be secure" |
| App password | K สร้างไม่ได้ ("don't know how") และผูกบัญชีเดียว |
| PC1 MCP (`desktop-rgk6jkb.tail8740ad.ts.net/mcp`) | **HTTP 502** — funnel ขึ้น แต่ backend `winremote-mcp` (127.0.0.1:8090) ดับ |
| ทางที่เหลือ | **Chrome บน PC1 login ค้างทั้ง 4 บัญชี** → อ่านเมล์ผ่าน `mail.google.com/mail/feed/atom` ได้ |

**สรุป:** อ่านเมล์ได้ที่ **PC1 เครื่องเดียว** ⇒ ทุกอย่างขึ้นกับ "PC1 ออนไลน์ไหม"

## สาเหตุ (Cause)
`winremote-mcp` บน PC1 ไม่ได้รัน (และไม่ได้ตั้งเป็น scheduled task) → funnel ตอบ 502 →
agent สั่ง PC1 ไม่ได้ → อ่านเมล์ไม่ได้. **ต้องมีคนที่เครื่องรันสคริปต์ซ่อม 1 ครั้ง**
(ไม่มี inbound route ทางฟิสิกส์ให้ pod ไปสตาร์ทโปรเซสบน PC1 เอง)

## วิธีแก้ (Solution) — ให้ ChatGPT ช่วย

ChatGPT บน PC1 คุม **หน้าจอ/คีย์บอร์ด PC1 ได้** ⇒ ให้มันรันคำสั่งซ่อมให้

### ขั้นที่ 1 — บอก ChatGPT ให้เปิด PowerShell **as Administrator** ที่ PC1 แล้ววางบรรทัดนี้

```powershell
iwr 'https://raw.githubusercontent.com/kongkeat938/ai-content-lab/main/ops/pc1_fix_remote.ps1' -OutFile "$env:TEMP\pc1_fix_remote.ps1" -UseBasicParsing; powershell -ExecutionPolicy Bypass -File "$env:TEMP\pc1_fix_remote.ps1" -Persist
```

**ไม่ต้องใส่ `-Token`** — สคริปต์ใช้คีย์เดิมในเครื่อง (`C:\AX-Runtime\winremote\winremote-auth.key`)
⇒ secret `PC1_MCP_TOKEN` ใน OpenHands ยังใช้ได้เหมือนเดิม
สคริปต์จะ: เปิด `--enable-tier3` · ตั้ง scheduled task ให้รันทุก logon · re-assert tailnet · พิสูจน์ด้วย `SHELL_PROOF` + `FILEWRITE_PROOF`

### ขั้นที่ 2 — รอจนเห็น `RESULT=OK` แล้วบอก ak

ak จะยืนยันด้วย: `PC1_MCP_URL=https://desktop-rgk6jkb.tail8740ad.ts.net/mcp python3 scripts/pc1_health.py`
→ ต้องได้ **`up`** (ไม่ใช่ `backend-down`)

### ขั้นที่ 3 — ak อ่านเมล์ผ่าน PC1

เมื่อ PC1 = `up`: เปิด Chrome profile ที่ login ไว้ (Profile 3 = farmmer.938 = ch2) ที่
`https://mail.google.com/mail/feed/atom` → ได้ XML รายการเมล์ → `mail_watch.py` รายงาน

## ทางเลือกถ้า ChatGPT สั่ง PC1 ไม่ได้
ให้ **K** รันคำสั่งขั้นที่ 1 เองที่เครื่อง (เปิด PowerShell as Administrator → วาง → Enter) — 1 ครั้ง

## ถ้าอยากให้ ak login Google เองได้ (ทางที่ 2)
ใช้ **Playwright** ในpod: `pip install playwright && playwright install chromium`
แล้ว ak login ด้วยอีเมล+รหัสที่ K ให้ — แต่ **ต้องมี 2FA** (Google บังคับ) ⇒ K ต้องให้รหัส
TOTP ใหม่ทุกครั้ง **ไม่ยั่งยืน** → ไม่แนะนำ. **PC1 ดีกว่า** เพราะ login ค้างอยู่แล้ว
