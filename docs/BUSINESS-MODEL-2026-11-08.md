## 2. โมเดลธุรกิจ (Revenue Model)

### 2.1 ลำดับรายได้ (ก่อน-หลัง) — มติเอกฉันท์

| ลำดับ | แหล่งรายได้ | เงื่อนไขเริ่ม | ทำไมลำดับนี้ |
|---|---|---|---|
| **1** | **AdSense (YPP)** | 1,000 subs + 4,000 ชม. | ประตูเดียวที่ให้ "รายได้ต่อวิว" จริง แต่มาช้า |
| **2** | **Affiliate** | เริ่มได้เลย (ไม่มีธรณี) | genx=หนังสือพัฒนาตัวเอง · dharma=หนังสือ/ของธรรมะ · kongkeat=ของใช้ในเรื่อง |
| **3** | **สินค้าดิจิทัล** | ผู้ติดตามจริง ~5-10k | e-book/เสียงสมาธิ/printable — margin สูงสุด |
| **4** | **โดเนท/สมาชิก** | หลัง YPP | dharma เหมาะสุด (บริบททำบุญ) |
| **5** | **หลายช่อง (ก็อปโมเดล)** | หลัง 1 ช่องพิสูจน์ได้ | **อย่าทำก่อน** — คูณปัญหา ไม่คูณรายได้ |

### 2.2 $500/ช่อง สมจริงแค่ไหน — ตอบตรง ๆ

RPM long-form ไทย ≈ $2 → $500 = **250,000 วิว/เดือน = 8,333/วัน/ช่อง**.
ตอนนี้ dharma (ดีสุด) ~7,500 วิว/เดือน → ต้องโต **~33 เท่า**.

> **ไทม์ไลน์จริง: 18-36 เดือน** ถ้าไม่มีคลิป breakout.
> **เป้าที่ควรตั้ง (panel เอกฉันท์):** เดือน 1-6 → **$50-100/ช่อง**; เดือน 12 → $500
> **บนช่อง dharma ก่อน** แล้วก็อป.

### 2.3 ตัวคูณที่แท้จริงคือ "ชั่วโมงดู" ไม่ใช่ "จำนวนคลิป"

watch time ปลดล็อก **ทั้ง** YPP **และ** รายได้ — เป็นตัวเดียวกัน.
หลักฐานจากข้อมูลเราเอง: long-form 120 นาที 292 วิว ให้ 9.32 ชม. (AVD 4%) —
ถ้า retention เป็น 50% ด้วยวิวเท่าเดิม จะได้ **~117 ชม. = 12 เท่า**.

⇒ **คันโยกแรงสุด = % ที่ดูจนจบ ไม่ใช่จำนวนวิว.** (เพิ่งแก้ไปวันนี้)

## 3. ทีม developer (AI Agent Team) — 5 ตัว

ทุกตัวคือสคริปต์ที่รันบน GitHub Actions ฟรี, ถูกขับโดย **foreman** (ไม่พึ่ง cron),
และมี **guard test** ของตัวเอง.

| # | Agent | หน้าที่ | ไฟล์ (มีอยู่จริง) | วัดผลด้วยตัวเลข | สถานะ |
|---|---|---|---|---|---|
| 1 | **Strategist** | อ่าน Analytics → เลือกหัวข้อ/niche | `studio_ai.py` + `advise.py` | retention trend, วิว/คลิป | ✅ มี |
| 2 | **Scriptwriter** | hook + โครงเรื่อง | `gen_*_scripts.py` + panel | retention 30 วิแรก | ✅ มี |
| 3 | **Producer** | เสียง+ภาพ+ตัดต่อ | `make_compilation.py`, `make_chapter_video.py` | render สำเร็จ, ต้นทุน/คลิป | ✅ มี |
| 4 | **Publisher** | title/thumb/desc/เวลาโพสต์ | `publish_*.py`, `set_thumbnails.py` | **CTR**, impressions | ✅ มี |
| 5 | **QA / Critic** ⭐ | ให้เกรด A-D, **veto ได้** | **`qa_gate.py` (ใหม่)** | % คลิปเกรด A/B | ✅ **สร้างวันนี้** |

**ใครคุมคุณภาพ = agent #5.** นี่คือช่องโหว่ใหญ่สุดที่ panel ชี้เหมือนกันหมด:
ระบบเดิม **ไม่มีประตูอนุมัติเลย** → ปล่อยทุกอย่างที่เรนเดอร์ออกมา รวมทั้งการ์ดนิ่ง
ที่ทำให้ AVD 5.2%. ตอนนี้ QA มีอำนาจ **บล็อก** คลิปที่ hook อ่อน/ภาพนิ่ง.

### 3.1 QA gate ทำงานอย่างไร (สร้างจริง 2026-11-08)

`scripts/qa_gate.py` อ่าน receipt ของ build แล้วให้เกรด A-D:

**Hard gate (พลาดข้อใด = veto ทันที, เกรด D):**
- verifier ต้องผ่าน (ไฟล์พัง = ห้ามปล่อยเด็ดขาด)
- ต้องมี **hook** และยาว 2-30 วิ
- **ภาพต้องเปลี่ยน**: ≥2 การ์ด และ **ไม่มีการ์ดใดยาวเกิน 8 นาที**
- true peak ≤ -3 dBFS

**Soft gate (มีผลต่อเกรด ไม่ veto เอง):** ความยาวในย่าน 15-40 นาที (คลิปเล่า/สอน) หรือ 110-130 นาที (ไฟล์นอน 120 นาที — รูปแบบที่ตั้งใจ), จังหวะเปลี่ยนภาพ

**ผลจริง:**
- dharma build ล่าสุด (29 การ์ด, hook 11s, 30.4 นาที) → **เกรด A**
- การ์ดนิ่งแบบเดิม (1 การ์ด/120 นาที, ไม่มี hook) → **veto (D)**
- veto เขียน `state=blocked` → `publish_batch` **ไม่ยอมอัปโหลด**

## 5. สิ่งที่ **ไม่ควรทำ** (และเหตุผล) — มติเอกฉันท์

1. **อย่าเพิ่มปริมาณอัปโหลด** — เพดานยังไม่เต็ม; เพิ่มคลิป = วิว 0 เพิ่ม + กินโควตาฟรี.
2. **อย่าทำ 3 ช่องเท่ากัน** — กระจายแรง = ไม่มีช่องไหนถึงเป้า. ทุ่ม dharma ก่อน.
3. **อย่าซื้อวิว/ซับ** — ผิด TOS = แบน.
4. **อย่าเปิด affiliate/สินค้า ก่อนมีคนดู** — ขายของให้ 0 คน = เสียเวลา.
5. **อย่าใช้ Shorts เป็นทางหลักไป 4,000 ชม.** — Shorts ไม่นับชม.ดูยาว.
6. **อย่าเพิ่ม agent/automation ก่อนแก้คุณภาพ** — = automate กระบวนการที่พัง.
7. **อย่าเปลี่ยนชื่อ/แฮนเดิลช่องบ่อย** — จำกัด 2 ครั้ง/14 วัน.
8. **อย่ากลับไปใช้การ์ดนิ่ง** — QA veto จะบล็อกเอง (ตั้งใจให้เป็นแบบนั้น).
