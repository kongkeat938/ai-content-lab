## สิ่งที่วัดได้วันนี้ (หลักฐาน ไม่ใช่คำอ้าง)

| ทาง | ผลจริง |
|---|---|
| pod → `imap.gmail.com:993` | ✅ **เปิด** — `* OK Gimap ready for requests from 34.45.0.142` |
| pod browser (headless) → Google | ❌ `signin/rejected` "browser may not be secure" |
| **chromium จริงบน Xvfb (headful)** → Google | ✅ **ผ่าน!** ถึงหน้า "Enter your password" ของบัญชีจริง |

chromium จริงบนจอเสมือน **ไม่ถูกบล็อก**

```

```

### ทาง B — ak ล็อกอินเองจากใน pod

```

GMAIL_USER=... GMAIL_PASSWORD=... python3 scripts/gmail_app_password.py --store
```

(ถ้ามี 2FA: `GMAIL_TOTP=<code>`)

## ไฟล์

- `scripts/pod_chrome.sh` — เปิด chromium headful + CDP (พิมพ์ endpoint ออกมา)
- `scripts/start_novnc.sh` — Xvfb + x11vnc + noVNC (K พิมพ์เองได้)
- `scripts/gmail_app_password.py` — ล็อกอิน → เปิดหน้า App Password → อ่าน 16 ตัว → เก็บ secret
- `scripts/mail_watch.py` — อ่าน IMAP (มีอยู่แล้ว; pod เข้าถึงได้)
