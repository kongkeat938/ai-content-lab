### P2 — health.py fail-open (บั๊กจริง แก้วันนี้) ⭐

- **Problem:** รัน `health.py` โดยไม่มี token → พิมพ์ `could not read runs: HTTP Error 401`
  แล้วยังสรุป **"all rails fresh"** และ exit 0. ยิ่งกว่านั้นถ้าใส่ `--alert` มันจะ **ปิด issue
  เตือนสุขภาพ** — กลบ alert จริงพอดีในจังหวะที่ระบบ "มองไม่เห็น" rails เลย.
- **Cause:** `main()` เขียนว่า `if "_error" not in runs: <ตรวจ stale>` แล้วปล่อยว่าง →
  `stale=[]` → รายงานว่าสดทั้งที่อ่านไม่ได้. (เอกสาร 2026-11-09 เคยอ้างว่า `_error` ถูกแก้
  — จริง ๆ แก้แค่รายชื่อ workflow 404 ไม่ใช่ fail-open นี้).
- **Solution:** "อ่านไม่ได้" เป็นสถานะของตัวเอง — `UNKNOWN`, exit 1, **ไม่ปิด alert**.
- **Execute:** แก้ `scripts/health.py` (เพิ่ม `blind` state) + เทสต์ใหม่ `scripts/test_health_blind.py`.
- **Verify (วัดสด):**
  - ไม่มี token → exit **1**, พิมพ์ `## rails UNKNOWN — could not read run history`.
  - มี token → exit **0**, `## all rails fresh`.
  - พิสูจน์ว่าเทสต์ **"ล้มได้"**: `git stash` health.py กลับเป็นเวอร์ชันเก่า → เทสต์ FAIL 4 ข้อ
    (`rc=0`, `all rails fresh` ยังโผล่) → restore → ผ่าน. ตรงตามกฎ K "guard must be able to FAIL".
  - commit + push แล้ว; `selftest.yml` เก็บเทสต์อัตโนมัติผ่าน glob `scripts/test_*.py`.

- **Execute:** โค้ด/พูล/rail เปลี่ยนแล้ว (commit `f3b24d1`, `c3607d3`). จำลองการเลือกของ rail:

## 2. ยืนยันแนวทางปัจจุบัน (current approach)

แนวทางเดิม **ถูกต้องและยังใช้** — มีหลักฐานสนับสนุน:

1. **ทุ่มที่ dharma.** วัด 7 วัน: dharma ทำ **47.8/48.5 ชม.** long-form ของทั้งระบบ = **98.6%**.
   เป็นช่องเดียวบนเส้น YPP จริง (genx funnel ตาย: 30,080 วิว → 0.6 ชม.).
2. **เข็ม = long-form watch-hours + retention@2min, ไม่ใช่จำนวนวิว.** ตัวเลขวิวสูง (61,711/28 วัน)
   หลอกได้ — long-form จริงแค่ 51.4 ชม.
3. **แก้ 2 นาทีแรกคือคันโยก.** dharma retention@2min 29% (71% ออกใน 2 นาที); hook concrete
   applied แล้ว รอวัด ~1 สัปดาห์.
4. **คุณภาพคลิป > ปริมาณ.** cap 3/24h, drip 1 คลิป/รอบ, กักคลิปแบน — ลดความเสี่ยง spam signal
   บนช่องเด็ก.
5. **ระบบออโต้ 100% + ติดตามด้วย invariant.** ไม่มี approval gate; ตัวตรวจต้อง "ล้มได้"
   (counter monotonic, health honest, learning loop อ่านชื่อจริง).

**ไม่มีอะไรต้องเปลี่ยนแนวทาง** — สิ่งที่ทำวันนี้คือ *ปิดรูรั่วของการติดตาม* (P2) และ
*ยืนยันว่าเครื่องยนต์เดินถูก* ไม่ใช่เปลี่ยนทิศ.
