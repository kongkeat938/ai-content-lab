## บริบทระบบ

ระบบอัตโนมัติ 100% บน GitHub Actions บริหาร 3 ช่อง YouTube ไทย:

- **genx** (ch1) — วิวเยอะสุด (32,690/28 วัน) แต่ funnel ตาย: long-form 1.5 ชม.
- **kongkeat** (ch4, ชื่อจริง "เรื่องเล่าอบอุ่นใจ") — Shorts ถูก feed ตัดการมองเห็น
  (2 วันล่าสุด 0 วิว); long-form 1-3 วิว/คลิป

## กฎที่ตั้งไว้ (จากที่วัดจริง 2026-11-10)

- kongkeat เคยถูก feed ตัด เพราะ hook เป็น "ฉากอบอุ่นแบน" ไม่มีปม → mid-retention 13.7%
  (เทียบ genx 62% / dharma 68%). จึงตั้งกฎ: **hook ต้องมี "ปมตึง"** (คำถาม/ความลับ/การจากลา/
  ความผิดหวัง) บังคับด้วย regex `_TENSION` ทั้งใน generator (`gen_short_scripts.py`) และ rail
  (`publish_shorts.py`).
- **การเรียนลูป**: `studio_ai.py` อ่าน Analytics → ถาม panel → เขียน
  `content/insights/<channel>.json` (มี `topics`). `gen_short_scripts.py` เอา `topics` นี้
  ไปใช้ตั้งหัวข้อ Shorts รอบถัดไป. จึงต้องมี `TOPICS_HINT` บอก panel ให้เสนอหัวข้อแบบ "ปมตึง"
  สำหรับ kongkeat โดยเฉพาะ
- มีเทสต์กัน: `scripts/test_pace.py::test_ch4_insights_tension` เช็คว่าทุกหัวข้อใน
  `content/insights/ch4.json` ต้องมี marker ปมตึง ไม่งั้น FAIL

## ต้นเหตุ (วัดแล้ว)

- ใน `studio_ai.py`: `TOPICS_HINT = {"kongkeat": "..."}` แต่ `question_for(channel)` ถูกเรียก
  ด้วย **"ch4"** (ชื่อช่องของ studio_ai = ch1/ch2/ch3/ch4) → `TOPICS_HINT.get("ch4")` = None
  → คำใบ้ปมตึง **ไม่ถูกส่งให้ panel เลย** → panel เสนอหัวข้อแบน → เขียนไฟล์แบน → เทสต์ FAIL.
- ยืนยันสด: `question_for('ch4')` ไม่มีคำว่า "ปมตึง"; `TOPICS_HINT` มีคีย์ `kongkeat` เท่านั้น;
  `GEN_ALIAS = {'ch4': 'kongkeat-story'}`.
- หมายเหตุ: `gen_short_scripts.py` มีตัวกรองทิ้งหัวข้อที่ไม่มีปมอยู่แล้ว (`cfg["require"]`),
  แต่ไฟล์ insights ที่ commit ไว้ยังแบน → เทสต์ (และ panel รอบถัดไป + `winners`) ยังเปื้อน.
