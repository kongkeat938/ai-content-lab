## 3. แนวใหม่ที่ล็อก

- **หัวข้อ:** ช่วงเวลาครอบครัวเจาะจง มี "ความสัมพันธ์ + การกระทำทางกาย"
  (พ่อ/แม่/พี่ + ทำกับข้าว/กอด/เย็บ/ต้มน้ำเกลือ)
- **โครง:** ฮุก = ช่วงเวลาเดียวที่เจาะจง → ปมขัดแย้งเล็ก ๆ → จุดจบอบอุ่น
- **กติกาฮุก (บังคับ):** มีความสัมพันธ์ + การกระทำทางกาย (วัดจริง: 460-1,083 วิว)
- **หยุด:** เรื่องคลาสสิก/เทพนิยาย (มัทนะพาธา, ไกรทอง, สังข์ทอง, จดหมาย) เป็นงานหลัก
  — ถ้าจะทดลอง ให้เป็น slot เล็ก ไม่ใช่แนวหลัก
- **เพลง/ภาพ:** เหมือนเดิม (SVG/Pillow + Wikimedia)
