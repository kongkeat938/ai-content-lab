# BRIEF — คลิปเก่ายอดวิวน้อย: วินิจฉัยถูกไหม + ควรทำอะไรต่อ (2026-11-06)

คุณคือที่ปรึกษาเติบโต/สร้างรายได้ YouTube ให้ช่องไทย 3 ช่อง. ตอบไทย กระชับ เรียงตาม
ผลตอบแทนต่อแรง และอ้างตัวเลขในบรีฟ. บอกชัดว่าอะไร *ไม่* ควรทำ เพราะอะไร.

## เป้าหมายธุรกิจ
ดัน 3 ช่องให้ผ่านเกณฑ์ YPP (1,000 subs + 4,000 ชม. long-form/12 เดือน หรือ 10 ล้านวิว Shorts/90 วัน).
YPP นับต่อช่อง. **ชั่วโมงจาก Shorts Feed ไม่นับเข้าเกณฑ์ 4,000 ชม.**

## ตัวเลขที่วัดจริง (206 คลิป ทุกช่อง, 2026-11-06)
- วิว median ต่อคลิป เมื่อเทียบกับจำนวน Shorts ที่โพสต์ในวันเดียวกัน:
  - 1-5/วัน → 14 · 6-10 → 317 · 11-20 → **334** · 21-40 → 221 · **41+/วัน → 1**
- วันที่ 2026-11-05 โพสต์ **89 Shorts ในวันเดียว → median 1 วิว** (ดีสุด 711, แย่สุด 0).
  ของ dharma 53 คลิป: 42 ได้ ≤3 วิว, 31 ได้ 0 วิว.
- ความยาว: Short 16-30 วิ median 187 · 31-45 วิ → 107 · **46-60 วิ → 2**.
- คลิป 61-300 วิ (ไม่เป็น Short ไม่เป็น long-form) → median 2 วิ (โซนตาย).
- long-form 10-11 นาที → median 2 วิ. long-form 120 นาที → 146 วิ แต่ 0.060 ชม./วิว.
- คลิปตาย 50/50 มีแท็ก, 49/50 เป็น public → แท็ก/privacy ไม่ใช่ปัญหา.
- ยอด sub: genx 104 · dharma 29 · kongkeat 9.

## สมมติฐานสาเหตุราก (ตรวจแล้วในโค้ด)
1. `publish_shorts.py` ตั้ง `--per-run` default = 0 (= อัปโหลดทั้งหมดที่ค้าง).
2. `publish-shorts.yml` trigger `push` บนไฟล์ manifest ที่ตัวมันเอง commit → โพสต์เสร็จ trigger ตัวเองซ้ำ.
3. เมื่อ pool ถูกเติม → push ยิง publish ทันทีโดยไม่ส่ง per_run → เททั้ง pool (89 คลิป).
⇒ คิดว่าเป็น **บั๊กของ rail ไม่ใช่คอนเทนต์แย่**.
